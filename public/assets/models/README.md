# Public 3D Models Directory (`public/assets/models/`)

Place `.glb` or `.gltf` model files here. 

For example, if you place `pine_tree.glb` here, it will be accessible at URL `/assets/models/pine_tree.glb`.

## Recommended Sources for Free Photorealistic 3D Trees:
1. **Sketchfab** (Filter: downloadable `.glb`, search: "pine tree", "snow pine tree", "fir tree")
2. **Poly Pizza** (poly.pizza)
3. **Quixel Megascans / AmbientCG** (Texture maps & bark materials)
